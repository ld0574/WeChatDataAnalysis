# 课程 Wiki 的耗时与加速方案

2026-11-04，用户要求修复首课表格、把自测改成最多五道选择题，并调查全量课程的处理速度。
首课的两天包含工作流实现、失败恢复、来源关联、覆盖核对和多次修补；不能作为每课固定推理时间外推。
现有流程仍然调用过碎，后续应减少重复输出、角色切换及无效结构修补，并保留完整原文覆盖验收。

## 实测依据

本机为 RTX 2080 Ti 11 GB。采样时功耗上限 180 W、约 61°C，原有上限 200 W 和 70°C 暂停规则继续生效。
本轮没有提高功耗，也没有为试验抢占正在运行的抽取、PDF、第二课账本和写作等待任务。

第二课前九个调度组的 28 份已保存模型响应：

| 指标 | 实测 |
| --- | ---: |
| 经过时间 | 41.1 分钟 |
| 模型服务记录的总耗时 | 22.5 分钟 |
| 其中输出生成 | 14.9 分钟 |
| 其中加载耗时指标 | 5.6 分钟 |
| 其中输入预填充 | 1.9 分钟 |
| 输入 / 输出 tokens | 213,210 / 49,097 |
| 提取 / 修补 / 审核响应 | 9 / 5 / 14 |

经过时间与模型服务记录相差约 18.6 分钟，包括共享 GPU 等待、调度及其他工作，不能全部算作 GPU 等待。
输出生成占服务耗时约 66%，加载指标约 25%；只提高功耗无法解决流程开销。
这九组是冻结的性能样本，不是第二课的当前完成组数，更不是整课成稿耗时。

本次确认的唯一视频清单为 340 个、825.0 小时、408.6 GiB。用户提到的 680 GB 可能另含课件或重复材料；
全量目标仍包括 340 节有声课程、2 份无声来源和全部可恢复课件，不能按这个视频大小缩减范围。

## 已完成的改动

每课读者自测最多五道选择题，统一独立出题、独立审核，不再在阅读页展示每小节开放题。
题目所选的小节编号由程序映射到完整真实原文，模型不必反复复制引文。题包按正文版本固定，已通过版本直接复用。
首课实际五题均已核对；复用路径实测零模型调用。原失败响应及预算保留，没有通过重置额度重新出题。
当前已启动写作配方仍可能生成内部旧题；彻底取消逐小节造题须随下一未启动配方实施，不能声称生产流程已全部采用。

## 完整输入分组容量测量

对第二课同一份 587 条完整原记录、274,804 字符，仅在 CPU 上测量备选分组；未写新任务清单、未消费生成预算、未改当前绑定。
输入包含目标原文、完整相邻上下文和真实提取提示，用当前 tokenizer 测量。每条原记录只分配一次，没有裁剪或改写。

| 每组字符阈值 | 组数 | 提取输入最大 tokens | 提取输入累计 tokens | 每组输出预留 | 最大请求上下文 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 12,000（当前） | 25 | 8,003 | 149,104 | 12,288 | 32,768 |
| 18,000（试点候选） | 17 | 11,586 | 145,110 | 12,288 | 32,768 |
| 24,000（后续候选） | 12 | 13,971 | 134,639 | 12,288 | 32,768 |

仅计一次提取加一次审核的基础请求数，对应 50、34、24 次，分别减少 32% 和 52%。
输出总量不会按相同比例减少；大组可能增加截断、遗漏、修补和 schema 处理成本。
当前测量只证明提取请求的输入容量；审核、修补、实际输出完整性和语义质量没有在新组大小下验证，不能宣称两倍提速。

精确字符串去重也测过：第二课 503 条课堂记录中 18 条重复，仅节省 2.4% 字符，不能解决主要耗时。
重复来源仍须保留各自身份和覆盖去向，不能直接丢掉它们。

## 下一步顺序

1. 在下一节尚未处理的课上，固定三组完整原记录及预算，先试 18,000 字符组。记录经过时间、输出 tokens、结构失败、修补数、完整原文遗漏和实际阅读结果；只在质量与完整性均过关后推广。24,000 字符组仍作为候选。
2. 对同一有限批次按角色集中调度：先提取，再统一独立审核，然后仅修补负面项并复核。独立审核保留两种模型，减少相邻请求反复换模型；共享 GPU 期间的实际收益须另测，不把理想加载节省当实绩。
3. 中间审核按每项保留明确判断，肯定项输出简短标志，负面项才写具体条件与缺失内容；不再让每个肯定项重复复述原文。整篇编辑、逐原文覆盖和负面意见仍保留。
4. 引文范围、真实 ID、覆盖分配和机械检查交给程序；写作模型专注概念规划与完整讲解。每课最后统一五道选择题，避免逐小节题目及其重复审核。

运行中的任务沿原配方继续，原失败、预算、暂停及停止标记保留。新试点不重跑已经验收的批次。
在得到新配方完整一课的实测结果前，不承诺全量完成日期或具体加速倍数。
