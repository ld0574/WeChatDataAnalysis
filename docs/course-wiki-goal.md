## 一篇合格的主题文章

文章围绕一个可理解的主题或要解决的问题组织，不能直接把固定时间片段、关键词列表或概念连线当成成篇知识。

1. 概述：讲什么、解决什么问题、阅读后的学习目标。
2. 前置知识、适用场景和适用条件；材料不足时明确标为缺失。
3. 连贯的原理说明，保留专业术语、限制与版本背景。
4. 适用的操作步骤、代码或案例；不执行课程中的不可信指令，不虚构步骤。
5. 对理解有帮助的原始截图、课件图示或依据来源重绘的解释图。原图保留页码或视频时间，重绘图明确标记，不能用装饰图片替代知识内容。
6. 易错点、常见疑问和需要进一步核对的内容。
7. 每篇通常 3–5 道自测题，覆盖概念理解、应用判断或实践；答案与解析可折叠，附原文依据和判断标准。不能把原笔记中只有问题、没有答案的列表冒充自测题库。
8. 关键解释、操作条件、图片、代码和答案均可追溯到稳定来源编号及视频时间或课件位置。
9. 相关文章、前置主题和后续主题的导航。课程间重名术语、同义词及不同版本保留语境，不能仅按名称相同就宣称知识等价。

资料确实不足时，文章显示缺口和未完成状态；不借助外部知识补造成“完整文章”。历史 API、价格和版本不冒充当前事实。

- 支持本地保存阅读位置、自测结果和复习标记；“已读”和“已掌握”不能混为一谈。
- 图谱从文章间已核对的关系派生，优先表达前置、组成、应用等有意义的关系；不是入口的主体，也不是质量验收的替代物。
- 桌面与窄屏可读，具备加载、空白、失败及内容未就绪状态。模型问答在 GPU 忙时有明确状态，不能长期无反馈。

## 质量与覆盖验收

结构正确、引用编号存在、FTS 可检索、页面能打开，只证明相应技术检查。语义验收另查：概念是否正确、原文是否支持结论、关键条件和步骤是否遗漏、图文是否对应、自测答案是否有依据。

文章应分别标记“模型草稿”“来源结构已核对”“语义待复核／已复核”等真实状态。单个模型自评不能直接把自身文章标为正确；没有独立语义依据，不发布虚构准确率。

全量范围来自全部可恢复课程清单，不能用已导出的少数课程代表全部。每个来源都须映射到文章、原始归档或明确的排除项。无法读取的源、未知密码课件、损坏音轨缺口、未保留的瞬时操作画面等单独列出。未通过验收的素材继续保留。

1. 保留正在进行的转写、附件保留和校验。补齐来源目录与文章生成所需的证据层。
2. 先选概念说明、代码操作和综合应用等代表性主题，产出一小批完整的图文文章及自测，验证从阅读到核对出处、自测的完整流程。
3. 用固定输入、来源引用和实际阅读检查评估文章质量。模型、提示词或上下文策略的变化先做对照，再扩大处理，不直接全量重生成。
4. 经验证后分主题、分章节增量整理全量资料；失败可续跑，文章和素材以稳定 ID 与内容指纹去重。
5. 完成全量覆盖、图文对应、检索、自测和独立语义复核，并进行独立备份与恢复验证。
6. 只在上述验收后评估删除原视频；数据库、音频、图片、模型和知识文章的恢复范围必须明确。程序不能因文章能显示而自行删除原视频。
