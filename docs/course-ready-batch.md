# 完整材料的后续写作批次

`course_textbook_ready_batch` 将目录里接下来三门已有完整原文、从未进入账本角色的课程，
接在真实健康的前驱之后。原选择器仍排除交付、预留和所有已尝试的清单；
三门内部按完整处理组数由少到多执行，不删减课程、记录、原文、课件或全文目标。

首次准备绑定全部原文等价证明、来源版本、模型、tokenizer、源码和准确前驱身份。
账本预检在模型调用前完成，仍沿用每阶段两次结构尝试、每单元一次语义修复的原预算。
首次写作即使用已验证的 2–12 段实际数量标签和同一数量约束下的引用索引。
争议账本断言隔离，完整争议原文进入写作；负面意见不因生成了正文而消失。
守护放在独立控制目录，避免改变作者绑定的不可变文稿载荷。

前驱仍运行时只等待，既不获取全课程 worker 锁，也不获取共享 GPU 锁。
必须核对 PID、创建时间、守护和实际 worker 都已退出、真实退出码为 0，
再从原请求和回执只读重建完整前驱，才允许运行新课程。
前驱失败、暂停、身份改变、原件或模型变更均停止，不自动重试或热恢复。
任一新课程失败后停止在下一课之前，不能通过重新准备或启动刷新原预算。

生成结果只作为内部完整稿保存。全文来源覆盖、课件与图片证据、整体编辑、自测和实际阅读
仍需验收；入口不发布读者文章，不删除视频，不把组数或稿件数当作成品数。
340 节音频、2 份无声来源和全部可恢复课件的 Goal 范围不变。
